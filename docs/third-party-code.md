# Bundled QR encoder

`qrcodegen.py` is the unmodified Python QR Code generator by Project Nayuki,
distributed under the MIT license preserved at the top of that file.

- Source: https://github.com/nayuki/QR-Code-generator/blob/3c6d0b3cefb4e049dc337e82237c9644399716a8/python/qrcodegen.py
- Upstream commit: `3c6d0b3cefb4e049dc337e82237c9644399716a8`
- SHA-256: `9f4ed1dd201dcb92b1bc0d6e14f46c754bcff0ce48580c5d7e8ace8f6926c8ef`

The app generates QR modules locally and renders them as inline SVG in print HTML.
No QR service, network call, or package installation is needed at runtime.
